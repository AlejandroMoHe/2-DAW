Tabla de las Etiquetas de HTML5 (Tema 3)


Etiqueta Definición Sintaxis de uso Ejemplo
Head Cabecera, parte superior de la página web <head> ... </head> <head>Título de la página</head>
HTML Delimita todo el documento HTML. <html> ... </html> <html>Contenido de la página</html>
Body Contiene el cuerpo del documento, es decir, el contenido de la página. <body> ... </body> <body>Hola mundo</body>
P Define un párrafo e introduce un salto dejando una línea en blanco antes de continuar. <p> ... </p> <p>Este es un párrafo.</p>
B Pone el texto en negrita. <b> ... </b> <b>Texto en negrita</b>
I Pone el texto en cursiva. <i> ... </i> <i>Texto en cursiva</i>
U Subraya el texto. <u> ... </u> <u>Texto subrayado</u>
Sub Pone el texto en subíndice. <sub> ... </sub> H<sub>2</sub>O
H1 Etiqueta de encabezado. Marca el nivel de encabezado. <h1> ... </h1> <h1>Título principal</h1>
A Se utiliza para crear enlaces hacia otros recursos o secciones. <a href="URL"> ... </a> <a href="https://www.google.com">Google</a>
Input Se utiliza para crear controles interactivos en formularios. Su funcionamiento depende del atributo type. <input type="tipo"> <input type="text">
Option Permite definir los elementos de una lista desplegable. <option> ... </option> <option>España</option>
Caption Añade un título a una tabla para identificar el tipo de contenido que muestra. <caption> ... </caption> <caption>Alumnos</caption>
Article Se utiliza para describir unidades de contenido de una página web. <article> ... </article> <article>Contenido del artículo</article>
Aside Define la barra lateral de una página web. Puede contener enlaces u otros contenidos. <aside> ... </aside> <aside>Enlaces relacionados</aside>
